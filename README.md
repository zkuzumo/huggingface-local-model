# Hugging Face Local Model

## Project Overview
This project demonstrates how to download and run pretrained Hugging Face models locally using Python.

## Technologies
- Python
- Hugging Face Transformers
- PyTorch
- Hugging Face Hub

## Features
- Download pretrained models
- Run sentiment analysis locally
- Perform text classification

## How to Run

1. Clone the repository.
2. Create and activate a virtual environment.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run:

```bash
python main.py
```

## Model
DistilBERT fine-tuned for sentiment analysis.
